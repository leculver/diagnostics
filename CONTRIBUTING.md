# Contributing to .NET Diagnostics

Thank you for your interest in contributing to the .NET Diagnostics repo! We welcome contributions from the community.

## Getting Started

1. Fork this repository and clone your fork locally.
2. Follow the [build instructions](README.md#building-the-repository) to set up your development environment.
3. Create a branch for your changes.
4. Make your changes, add tests where applicable, and ensure existing tests pass.
5. Submit a pull request.

## Contribution Guidelines

This project follows the general [.NET contribution guidelines](https://github.com/dotnet/runtime/blob/main/CONTRIBUTING.md). Please review them before submitting a pull request.

Key points:

- **Sign a Contributor License Agreement (CLA)** -- You will be asked to sign a CLA before your pull request can be accepted. See [dotnet CLA](https://cla.dotnetfoundation.org/) for details.
- **Follow the coding style** -- Match the style used in the files you are editing.
- **Write tests** -- Add or update tests to cover your changes when possible.
- **Keep changes focused** -- Submit separate pull requests for separate issues.

## Reporting Issues

If you find a bug or have a feature request, please [open an issue](https://github.com/dotnet/diagnostics/issues/new/choose).

## Code of Conduct

This project has adopted the [.NET Foundation Code of Conduct](https://dotnetfoundation.org/code-of-conduct). See [CODE-OF-CONDUCT.md](CODE-OF-CONDUCT.md) for details.
